# ChatGPT 历史导航

[English](README.md) | 简体中文 | [日本語](README.ja.md)

这是一个用于浏览和跳转 ChatGPT 完整对话历史的浏览器扩展。它在对话旁显示时间线，方便浏览和回看长对话。

## 功能

- 显示完整对话历史，包括页面尚未加载的消息。
- 鼠标悬停或键盘聚焦时间线项目时，预览当前提问和助手回复。
- 点击时间线项目跳转到对应消息；目标消息未加载时会自动加载更早的历史。

## 安装

### 环境要求

- Node.js
- [pnpm](https://pnpm.io/)

### 构建

构建扩展：

```sh
pnpm install
pnpm build

# Firefox
pnpm build:firefox
```

### 加载扩展

#### Chromium 内核浏览器

打开浏览器的扩展管理页，启用开发者模式，加载 `.output/chrome-mv3`。

#### Firefox

打开 `about:debugging`，加载 `.output/firefox-mv2/manifest.json`。

## 原理

### 历史加载与同步

进入对话时，扩展监听 ChatGPT 发出的历史记录请求，并将响应解析为统一的消息列表。如果单次响应不完整，就通过 ChatGPT 自身的接口按游标继续请求更早的历史分页，合并至完整历史。结果保存在内存缓存中。

主动获取历史时，扩展会先尝试 ChatGPT 的完整对话接口。如果该接口不受支持，就回退到分页接口，按游标依次获取并合并所有页面。

页面侧脚本还会监听对话更新，将新消息、编辑和重新生成合并到同一缓存中。切换对话或账号时，旧缓存会被清理。

### 消息定位

点击时间线项目后，扩展首先调用 ChatGPT 自身的导航机制。如果目标消息尚未出现在 DOM 中，扩展会请求 ChatGPT 的定向历史加载器获取目标，并观察分页状态和 DOM 变化，等待消息渲染完成。如果原生定位不可用，则回退到在 DOM 中查找已渲染的消息或占位元素并滚动定位；如果定向历史加载不可用，则报告导航失败，不猜测位置。

## 隐私

扩展仅为显示时间线、预览消息、加载历史和定位对话而访问 ChatGPT 对话内容及当前登录会话。数据只在本地处理并保存在内存中，不会发送给开发者或任何第三方服务；网络请求仅发送到 ChatGPT 自身接口，不使用分析或跟踪。
