# ChatGPT History Navigator

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語

ChatGPT の会話履歴全体を閲覧・移動するブラウザー拡張機能です。会話の横にタイムラインを表示し、長い会話を確認しやすくします。

## 主な機能

- ページにまだ読み込まれていないメッセージを含む、会話の全履歴を表示。
- タイムライン項目にホバーまたはフォーカスすると、現在のプロンプトと返信をプレビュー。
- タイムライン項目をクリックして移動。未読み込みの場合は過去の履歴を自動で読み込み。

## インストール

### 必要な環境

- Node.js
- [pnpm](https://pnpm.io/)

### ビルド

拡張機能をビルドします。

```sh
pnpm install
pnpm build

# Firefox
pnpm build:firefox
```

### 拡張機能を読み込む

#### Chromium 系ブラウザー

拡張機能管理ページでデベロッパーモードを有効にし、`.output/chrome-mv3` を読み込みます。

#### Firefox

`about:debugging` から `.output/firefox-mv2/manifest.json` を読み込みます。

## 仕組み

### 履歴の読み込みと同期

会話を開くと、ChatGPT が発行する履歴リクエストを監視し、レスポンスを統一したメッセージ一覧に変換します。レスポンスが不完全な場合は、ChatGPT 自身のエンドポイントをカーソルで順に呼び出し、過去のページを結合して履歴全体を構成します。結果はメモリキャッシュに保持します。

履歴を直接取得するときは、まず ChatGPT の会話全体用エンドポイントを試します。対応していない場合はページング用エンドポイントにフォールバックし、カーソルをたどって全ページを結合します。

ページ側のスクリプトは会話の更新も監視し、新しいメッセージ、編集、再生成を同じキャッシュに反映します。会話やアカウントを切り替えると、以前のキャッシュを破棄します。

### メッセージの位置特定

タイムライン項目を選択すると、まず ChatGPT 自身のナビゲーションを使います。対象が DOM にない場合は ChatGPT の対象履歴ローダーに読み込みを依頼し、ページングと DOM の変化を監視してメッセージの描画を待ちます。ネイティブの表示処理が使えない場合は、DOM から描画済みのメッセージまたはプレースホルダーを探してスクロールします。対象履歴の読み込み自体が使えない場合は、推測せずナビゲーションエラーを表示します。

## プライバシー

この拡張機能は、タイムラインの表示、メッセージのプレビュー、履歴の読み込み、会話の移動に必要な範囲でのみ、ChatGPT の会話内容とログイン中の ChatGPT セッションにアクセスします。データはローカルで処理してメモリ上に保持し、開発者や第三者のサービスには送信しません。通信先は ChatGPT 自身のエンドポイントのみで、分析やトラッキングは使用しません。
